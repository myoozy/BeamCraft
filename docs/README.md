# BeamCraft documentation

This directory contains topic-specific engineering material that is useful to
maintainers but is not a repository-wide entry point.

## Categories

- `investigations/` — performance investigations, measurements, experiments,
  failed approaches, and open questions.
- `designs/` — concrete designs that are still being evaluated or prepared for
  implementation.
- `decisions/` — short records of decisions that have become stable project
  policy.

The categories are intentionally created as needed. The root-level
`ARCHITECTURE.md` and `SOURCE_PROVENANCE.md` remain root documents because
they are repository-wide references and are linked by project instructions,
licensing material, and source comments.
